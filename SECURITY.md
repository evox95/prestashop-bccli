# Security Policy

## Reporting a vulnerability

Report vulnerabilities privately by emailing **contact@bestcoding.net**.
Please do not open a public issue for a security report until it has been
addressed.

Include enough detail to reproduce the issue: the PrestaShop and PHP
versions involved, the command or input that triggers it, and the expected
versus actual behaviour.

## Supported versions

Fixes are made against the latest `1.x` release. The CI matrices cover
PrestaShop 1.7.8, 8.0, 8.1, and 8.2; the 1.7 port was locally tested on
PrestaShop 1.7.8.11. See [`README.md`](README.md) for requirements and caveats.

## No support SLA

This project is provided free of charge, without a support SLA. Reports are
reviewed on a best-effort basis; there is no guaranteed response or fix
timeline.
